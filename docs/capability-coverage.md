## What do the skills add to the MCP?

The MCP supplies generation and editing tools. A skill chooses a coherent workflow around them: inspect an accepted still before motion, reuse original references, preserve exact copy in editable layers, complete asynchronous jobs without duplicate paid retries, and deliver the requested files. The [AURORA kit](../examples/aurora-listing) demonstrates several outputs from one new generation. The [Nori explainer](../examples/nori-explainer) demonstrates assembled image, speech and motion assets, with its failures and review limits included.

These examples establish specific delivered artifacts, not a general quality ranking. Compare services using the same brief, references, allowed tools, budget and success criteria; include every failed attempt and judge the final exported media. Installs, stars and skill counts do not establish customer value.

## What still depends on tools outside these instructions?

Magic Hour's current creation MCP does not expose an equivalent to Soul ID training, a 3D-generation endpoint or a general timeline assembly endpoint. Exact SVG/PDF/PPTX composition requires an available design or document tool; local MP4 assembly requires a compositor such as FFmpeg. Do not assume those tools exist merely because a skill mentions them.

Higgsfield also documents [website and game workflows](https://github.com/higgsfield-ai/skills/tree/fb18134b4aabe99c4bf7ff01c8f4883400efc80d/higgsfield-websites). This cookbook supplies media for those projects; it does not publish a website or deploy a game. Use an appropriate development workflow when that is the actual job.

## How can I cite an example accurately?

Link directly to the case README and original output, name the operation and model used, and include the recorded date, attempts, cost and limitations. Use a commit permalink when reproducibility matters. Do not turn an accepted example into a claim of perfect identity, marketplace approval, higher conversion, retention or search visibility. None of those business outcomes has been measured by this repository.
